## 🚀 Projects

### 🧪 API Workspace

A collaborative API testing and management platform inspired by tools like Postman, designed to manage workspaces, collections, API requests, authentication, execution history and collaboration.

**Technologies:** Spring Boot, Java, React, PostgreSQL, JWT, WebSockets.

### 💬 Askora – Live Q&A That Deduplicates Itself

A real-time Q&A platform designed to eliminate duplicate questions by intelligently clustering similar questions and ranking them based on audience demand.

**Technologies:** Next.js, TypeScript, Appwrite, AI embeddings, Vector Search,Redis, Groq.

### 🌐 Mini Raft

Exploring distributed systems and implementing the Raft consensus algorithm to understand leader election, log replication and distributed coordination.
